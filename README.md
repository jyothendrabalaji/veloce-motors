## 🌟 Highlights & Design System

- **Editorial Luxury Palette:**
  - Carbon Black Background (`#08090c`)
  - Matte Gunmetal Cards (`#111318`)
  - Brushed Silver Text (`#f4f4f5`) & Slate Secondary (`#9ca3af`)
  - Racing Crimson Accent (`#e11d48`)
  - Crisp Hairline Borders (`1px solid rgba(255, 255, 255, 0.08)`)
- **Typography:**
  - Headings: `Plus Jakarta Sans` & `Syne`
  - Body: `Inter`
  - Metrics & Telemetry: `JetBrains Mono`
- **Micro-Interactions & Polish:**
  - Sticky glassmorphism header with `backdrop-filter: blur(14px)`
  - Smooth hover zoom on high-resolution sports car photography
  - Elevation card lift with subtle crimson rim-light shadow
  - Pure CSS responsive mobile navigation drawer (zero external dependencies)

## 🏛️ Sections Included

1. **Sticky Glassmorphism Navbar:** Brand monogram, smooth-scroll anchor links, and quick CTA.
2. **Cinematic Hero:** Full-bleed dark sports car imagery with dark gradient scrim, bold headline, dual CTAs, and a 3-stat performance telemetry strip (`0-100 km/h: 2.8s`, `Top Speed: 330 km/h`, `Power: 720 HP`).
3. **Fleet Showcase Grid (3 Columns):** Flagship models featuring verified photography, pricing in INR, quick stats, and direct links.
4. **Key Engineering Pillars (4-Card Grid):** Carbon-Ceramic Braking, Active Aerodynamics, Adaptive Air Suspension, and Hand-Stitched Alcantara Cockpit with custom inline SVGs.
5. **Technical Spotlight (Split View):** Aerodynamic profile view paired with a comprehensive mechanical parameters table for the flagship GT-R.
6. **Side-by-Side Model Comparison:** Horizontally scrollable dark-mode matrix comparing prices, powertrains, outputs, ranges, and architectures.
7. **Boutique Atelier & Test Drive (2-Column Split):**
   - *Left:* Jubilee Hills, Hyderabad Flagship Atelier details, operating hours, concierge hotline, and private appointment expectations.
   - *Right:* Full dark-mode test drive reservation form with date/time selectors and custom inputs.
8. **Editorial Footer:** Wordmark, social media handles, fleet directory, and copyright legal bar (`© 2026 Veloce Motors India. All rights reserved.`).

## 🚀 Quick Start & Local Preview

Clone the repository and open `index.html` in any web browser:

```bash
git clone https://github.com/jyothendrabalaji/veloce-motors.git
cd veloce-motors
# Open directly in your browser:
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux
```

No node modules, no build steps, zero bundle overhead.
